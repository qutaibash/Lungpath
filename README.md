# LungPath web app

Built output of the LungPath web app: pulmonary nodule (BTS 2015) and lung cancer (NICE NG122) decision support for UK clinicians.

Open https://qutaibash.github.io/lungpath/ in Safari on an iPhone, then tap Share and **Add to Home Screen**.

Draft content, not clinically validated. Source code is kept in a separate private repository.
